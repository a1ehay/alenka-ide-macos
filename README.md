# a1enka — AI Code Assistant

Локальный AI-помощник для редактирования кода. Работает полностью на вашем ПК.

## ⚡ Быстрая установка

### macOS

1. **Скачайте проект** и распакуйте.
2. **Откройте Терминал** в папке проекта.
3. **Запустите установку:**
   ```bash
   chmod +x install.sh
   ./install.sh
   ```
