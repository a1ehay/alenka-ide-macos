# 🧠 a1enka

**Локальный AI-помощник для редактирования кода.**  
Работает прямо в вашем браузере и редакторе кода. Никаких облаков, полная приватность ваших данных и установка **без использования терминала**.

---

## ✨ Возможности

- 🔒 **100% Локально:** Использует модель `qwen2.5:1.5b` через Ollama. Ваш код никогда не покидает ваш компьютер.
- 🧩 **Умная интеграция:** Не просто перезаписывает файл, а находит похожие функции и аккуратно обновляет их, сохраняя остальной код нетронутым.
- 🚀 **Установка в один клик:** Никаких команд в терминале. Просто двойной клик по установщику.
- 🍏 **Нативный Menu Bar:** Удобное управление сервером через иконку в верхней строке меню macOS.
- 🎨 **Современный UI:** Темная и светлая темы, плавные анимации и всплывающие уведомления.

## ⚡ Быстрый старт (macOS)

### Шаг 1: Скачивание
Скачайте архив с проектом и распакуйте его в любую удобную папку.

### Шаг 2: Установка (без терминала!)
1. Откройте распакованную папку `a1enka`.
2. Найдите файл **`Install a1enka.app`** и сделайте по нему **двойной клик**.
3. Появится окно с описанием. Нажмите **"Установить"**.
4. macOS попросит ввести ваш пароль администратора (это стандартная процедура для установки системных компонентов, таких как Node.js и Ollama). Введите его.
5. Дождитесь уведомления в правом верхнем углу экрана: *"✅ Установка завершена! Приложение a1enka появилось на Рабочем столе"*.  
   *(Это может занять 2–5 минут в зависимости от скорости интернета, так как скачивается нейросеть ~1 ГБ).*

### Шаг 3: Установка расширения в Firefox
1. Откройте браузер **Firefox**.
2. В адресной строке введите: `about:debugging#/runtime/this-firefox`
3. Нажмите кнопку **"Загрузить временное дополнение..."**.
4. Перейдите в папку `a1enka/extension/` и выберите файл `manifest.json`.
5. Иконка **a1enka** появится на панели инструментов Firefox.

### Шаг 4: Запуск
1. Перейдите на **Рабочий стол** и найдите приложение **`a1enkaMenuBar.app`**.
2. Запустите его (можно перетащить в Dock для удобства).
3. В верхней строке меню (возле часов) появится иконка `a1enka`.
4. Кликните по ней и выберите **"▶️ Запустить сервер"**.

## 📖 Как пользоваться

1. Откройте ваш проект в VS Code (или любом другом редакторе).
2. Скопируйте код или текст, который нужно улучшить, в буфер обмена (`Cmd + C`).
3. Кликните на иконку **a1enka** в Firefox.
4. В первый раз укажите **путь к папке вашего проекта** (например, `/Users/name/Documents/MyProject`) и нажмите "Подтвердить".
5. Введите **путь к файлу** внутри проекта (например, `src/components/Button.js`).
6. Нажмите **"ОТПРАВИТЬ БУФЕР В ИИ"**.
7. Через несколько секунд файл в вашем редакторе кода **автоматически обновится** с учетом новых изменений!

---

## ⚙️ Как это работает

1. **Расширение Firefox** считывает содержимое вашего буфера обмена.
2. Оно отправляет данные на локальный **Node.js сервер** (порт 3000).
3. Сервер читает **существующий файл** на вашем диске.
4. Сервер отправляет в **Ollama** (локальную нейросеть) промпт, содержащий и старый код, и новый, с инструкцией аккуратно их объединить.
5. Полученный результат сервер записывает обратно в файл. VS Code мгновенно подхватывает изменения.

## 💻 Системные требования

- **ОС:** macOS 11 (Big Sur) или новее (поддерживаются как Intel, так и Apple Silicon M1/M2/M3).
- **ОЗУ:** 8 ГБ и более (рекомендуется).
- **Место на диске:** ~2 ГБ свободного места (для Node.js, Ollama и модели).
- **Браузер:** Mozilla Firefox.

## ❓ Частые вопросы (Troubleshooting)

**В: При установке программа просит пароль. Это безопасно?**  
О: Да, это стандартное окно безопасности macOS. Оно требуется только для того, чтобы установить Homebrew, Node.js и Ollama в системные директории.

**В: Я нажал "Отправить", но ничего не происходит.**  
О: Убедитесь, что:
1. Сервер запущен (кликните по иконке в строке меню, там должно быть написано "✅ Работает").
2. Вы действительно скопировали текст в буфер обмена перед нажатием.
3. Путь к файлу указан верно (например, `index.js`, а не просто `index`).

**В: Нейросеть удалила мой старый код!**  
О: Модель `qwen2.5:1.5b` очень хорошо справляется с задачами, но для сложных файлов старайтесь копировать в буфер обмена только ту функцию или блок кода, который нужно изменить, а не весь файл целиком.

## 🛠️ Для разработчиков

Если вы хотите внести изменения в исходный код:
- Логика сервера находится в папке `server/`.
- Исходный код Menu Bar приложения (Swift) находится в папке `a1enka-menu-bar/`.
- Для пересборки приложения используйте скрипт `./build-menu-bar.sh` в терминале.
